ValuesRecheck

定義

  • 種別: function
  • 定義箇所: src/backend/executor/nodeValuesscan.c:179

目的

EvalPlanQual（EPQ）実行時に、タプルの再チェックを行うためのアクセスメソッドルーチンです。

シグネチャまたは形状

static bool ValuesRecheck(ValuesScanState *node, TupleTableSlot *slot);

入力と出力

  • 入力:
  • node: ValuesScanState 構造体へのポインタ。
  • slot: 再チェック対象の TupleTableSlot。
  • 出力:
  • bool: 常に true を返します。

前提条件と不変条件

  • VALUES 句によるスキャンはメモリ上の定数リストを扱うため、物理的なテーブルスキャンとは異なり、再チェックの必要がない（常に有効である）という不変条件に基づいています。

アルゴリズムまたは振る舞い

  • 内部で特別な処理を行わず、即座に true を返します。これは、VALUES スキャンにおいてタプルが常に最新かつ有効であることを示しています。

呼び出し元と呼び出し先

  • 呼び出し元: ExecScan 経由で EvalPlanQual 実行時に参照されます。
  • 呼び出し先: なし。

関連データ構造

  • ValuesScanState: VALUES スキャンノードの実行状態を保持する構造体。
  • TupleTableSlot: タプルを保持するためのスロット。

失敗モードと境界条件

  • 特になし。常に成功（true）を返します。

保守担当者向けメモ

  • 本関数は ExecScanRecheckMtd インターフェースを満たすためのスタブ的な実装です。将来的に VALUES スキャンに動的な要素が追加されない限り、この挙動は変更不要です。
