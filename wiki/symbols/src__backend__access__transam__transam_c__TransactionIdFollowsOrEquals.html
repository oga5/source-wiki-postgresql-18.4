TransactionIdFollowsOrEquals

定義

  • 種別: function
  • 定義箇所: src/backend/access/transam/transam.c:328

目的

2つのトランザクションID（XID）を比較し、id1 が id2 に対して論理的に後続するか、または等しいかを判定する。

シグネチャまたは形状

bool TransactionIdFollowsOrEquals(TransactionId id1, TransactionId id2)

入力と出力

  • **入力**:
  • id1: 比較対象のトランザクションID。
  • id2: 比較基準となるトランザクションID。
  • **出力**:
  • bool: id1 >= id2 が真であれば true、そうでなければ false を返す。

前提条件と不変条件

  • XIDは32ビットの循環値であるため、通常の比較演算子（>=）を直接使用することはできない。
  • TransactionIdIsNormal で判定される「正規の」XID（FirstNormalTransactionId 以上）同士の比較において、ラップアラウンドを考慮した論理的な前後関係が保証される。

アルゴリズムまたは振る舞い

1. id1 または id2 が正規のXIDでない場合、通常の比較演算子 id1 >= id2 の結果を返す。 2. 両者が正規のXIDである場合、id1 - id2 を int32 型にキャストして差分 diff を算出する。 3. diff が 0 以上であれば true を返し、負であれば false を返す。これにより、循環するXID空間における論理的な順序を判定する。

関連データ構造

  • TransactionId: トランザクションを一意に識別する32ビット整数型。

失敗モードと境界条件

  • 特殊なXID（BootstrapTransactionId, FrozenTransactionId 等）が入力された場合、循環を考慮した比較ではなく、単純な数値比較が行われる。

保守担当者向けメモ

  • 本関数はXIDのラップアラウンドを正しく処理するための重要なユーティリティである。XIDの比較を行う際は、直接的な比較演算子ではなく必ず本関数または関連する TransactionIdPrecedes 等を使用すること。
